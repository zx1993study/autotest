## 保护与限制

- ID 优先来自本次新增响应，否则必须匹配本次流程的唯一标记。归属校验不通过或必需变量缺失，不向后传递 ID。
- 默认失败即停，不自动重试写操作，不用历史业务 ID 作为修改、删除目标。流程停止后可能留下本次数据，需要人工核查。
- 线上拜访和批量计划的列表首条不是目标时明确失败，不扩大查询或采用其他记录代替。
- 活动申请当前模板不保存备注，新增也不返回申请 ID；未确认可靠归属路径前，增删场景不能启用。
- 退货新增进入审核中，编辑、删除可能受业务状态限制；不自动修改审批状态。采购入库的审批启动告警也保留，不强行改成通过。
- 督办没有删除接口，新增的任务不会自动清理；撤销不等于删除，未擅自加入撤销动作。
- 已启动的后端需要重启到当前代码，再执行新流程；本轮未重启服务，也未执行真实写操作的闭环回归。

完整配置 ID 见同目录 `manifest.json`；复用与生成方式见 `docs/api-crud-campaign.md`。
