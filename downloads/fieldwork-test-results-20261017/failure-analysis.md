# 外勤小星失败原因分析

执行范围：50 个已审核隔离/只读的 API 功能场景，43 通过、7 失败。小程序原生及同源 H5 各 244 个用例因运行环境缺失而阻塞，均未计为 UI 通过。API 回归不代替 UI 测试。

## 业务缺陷及契约问题

| 场景 | 批次 | 接口 | 结果与原因 | 处理建议 |
|---|---:|---|---|---|
| #16415 转换数量与装箱规格不符 | #17608 | POST /business/warehouse/230/inventory/convert | 固定装箱比例 1:24，却允许源数量 1、目标数量 25；HTTP=200、code=200，提示库存转化成功。预期业务拒绝未发生。 | 保留拒绝断言。由服务端按商品装箱规格计算/校验目标数量，不能信任客户端任意填写。 |
| #16302 活动审批通过 | #17347 | POST /business/activityTypeConfig | 创建活动类型即被 code=500 拒绝：“开启活动执行上报时，必须配置活动执行模板字段”。请求 needExecuteReport="0"，却触发“开启”校验。没有进入活动审批。 | 核对服务端是否将非空字符串 "0" 当作 true，并以 OpenAPI/字典约定统一布尔/枚举处理；未确认契约前不把它改成成功或预期拒绝。 |
| #16303 活动审批拒绝 | #17348 | POST /business/activityTypeConfig | 与 #16302 相同的活动类型前置失败。不能报告“活动拒绝审批已验证”。 | 修复前置后再跑通过与拒绝两个分支。 |
| #16017 仓库组合查询 | #17622 | GET /business/warehouse/list | 条件为 delFlag=0、updateBy=1、updateTime=2026-10-17 13:47:02，HTTP=200、code=200；返回 50 条，其中多条不符合 updateTime 条件。 | 若接口约定支持该条件，则为过滤未生效；若不支持，则需从查询策略及接口字段中移除这个条件。不能仅凭 code=200 判定查询正确。 |

上述缺陷归类以本次请求/响应为证据；未获得服务端源码，关于字符串布尔处理及过滤实现的解释属于待源码确认的推断。

## 断言与流程配置不匹配

| 场景 | 批次 | 失败节点 | 证据及分析 |
|---|---:|---|---|
| #16295 终端销售审批拒绝 | #17095 | sales_verify_detail | HTTP/业务码、订单 ID、拒绝状态 "4"、仓库、商品和数量断言均通过；仅订单 remark 不相等。实际 remark 变成了本批次审批备注（原标记 +“_审批核对”），用例仍期待创建时备注。业务拒绝动作已成功，失败不等于拒绝失效。需确认“审批是否允许覆盖订单备注”，再决定修正断言还是提业务字段覆盖缺陷。 |
| #16296 直营销售审批通过 | #17096 | sales_direct_process | 查询到真实新订单的审批实例，实际 businessType=sales_order、workflowId=12，用例期待 sales_order_direct、24。当前输入与预设直营流程不匹配；在审批前已停止，不能报告审批通过已验证。 |
| #16297 直营销售审批拒绝 | #17097 | sales_direct_process | 同 #16296，失败发生在流程识别，尚未执行拒绝。应先核对销售仓库、客户类别和销售类型实际匹配的流程，不通过删除审批人/节点检查来强行放行。 |

同轮新的库存核对流程中，总仓/直营仓与前端、直营商、KOL 客户的通过、拒绝场景均通过，说明旧 #16296/#16297 的失败不能简单归为“所有直营销售审批接口不可用”。

## 正常的业务拒绝

以下异常场景通过，表示系统按预期拒绝了操作，并核对库存未发生不允许的变化，并非“接口报错就是测试失败”：

- #16311 超库存销售、#16312 仓库无对应商品、#16315 可用库存为零时追加销售。
- #16359 全部库存锁定后尝试拆箱。
- 客户、采购、销售及退货的审批拒绝分支中，已通过场景按业务拒绝后的状态与库存判断。

逐节点的正常拒绝依据见 summary.json 中的 expected_business_rejections。没有 SQL 异常、未登录、权限错误被当成正常参数校验通过。

## UI 阻塞与平台验证

- 微信原生小程序：平台未连接 uni-automator/微信开发者工具节点。批次 #17356 的 244 个结果均为 blocked；早期 #17087 因开发热重载中断，已保留历史，不计入实际业务通过率。
- 同源 H5：项目未配置 miniapp_h5_url，批次 #17100 的 244 个结果均为 blocked。管理端地址不能当作小程序 H5 地址。
- 登录态、隔离数据、原生地图/相机/扫码以及人工业务步骤未验证，后续需补齐执行条件。
- 本轮验证了测试平台的导入幂等、业务关联、写入确认取消/接受、结果展示、桌面/移动端布局。这些是平台功能验证，不是外勤小星业务 UI 通过。
- 没有修改外勤小星业务服务代码，也没有为了变绿放宽现有业务断言。
