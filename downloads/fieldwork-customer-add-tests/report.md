## 输入与数据隔离

可编辑参数：`customer_name`、`phone`、`cooperation_status`、`manager_names`、`remark`。必填规则来自源码：名称、合作状态、客户经理。客户经理按 UI 昵称选择；本轮只读核实其对应当前登录管理员 ID 1，未分配给其他人员。

客户名模板：`青禾便利店_回归_{{timestamp_ms}}_{{random_digits:6}}`。一次执行内填写、查询和断言使用同一冻结值；不同执行产生新的唯一值。正常用例未填写非必填手机号，不生成真实联系人信息。

## 实跑中修复的问题

- 任务 18011：通用弹窗标题定位匹配多个元素，所有用例在填写前失败。改为限定新增弹窗 `aria-label` 和直接子标题、页脚。
- 任务 18027：客户经理控件的只读占位输入被前景搜索输入遮挡。改为定位该多选框内的可交互搜索输入，未使用强制点击；该批正常用例未提交。
- 任务 18043：正常新增与查询成功，但详情按钮定位误用了普通表格体类名。修正为固定操作列中的指定客户详情按钮；该批四条异常用例已通过。
- 任务 18059、18065：最终全量通过。失败任务和版本历史均保留；原用例 ID 74–83 重新绑定修复版本，没有删除失败结果或放宽断言。

- `11355-success.zip`、`11363-success.zip`：两个路由的正常新增脚本包。
- 其余 8 个 ZIP：对应字段校验脚本包。
