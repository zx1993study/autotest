## 平台执行

- 刷新登录页功能详情，确认显示账号、密码、验证码三个参数及各用例绑定的脚本版本。
- 正常登录选择本地有头执行。验证码开启时在目标浏览器中填写，再通过平台的人工继续按钮继续；验证码关闭时不等待人工输入。
- 密码沿用旧用例并加密保存。修改密码通过用例编辑表单，未修改则保留；不回显密码原文。
- 账号为空、密码为空等负向用例必须保留“异常输入用例”标记，使空值送到页面验证，而非被平台必填检查提前拦截。
- 含密码的用例不生成截图、录屏或登录态快照，不调用 AI 或 Stagehand，不自动复用管理员登录态。
- 使用“本机 Web 开发节点（本地后端）”，该专用源码 Agent 已启动；原远程节点配置未修改。系统重启后在项目根目录执行 `.venv/Scripts/python.exe scripts/fieldwork_login_platform_verify.py` 可重新启动，默认不会执行用例。
- 密码用例只列出与当前后端密码通道匹配的节点。共享数据库的多个后端还须共享持久化密码密钥。

## 本地脚本

`success/`、`username/`、`password/`、`both/` 分别对应四种参数化脚本包。每个包包含 `run.py`、`steps.json`、`inputs.json` 和共享运行时，不包含真实账号、密码或 Token。

在需要的包内配置 `inputs.json` 中的 `username`，密码由运行时安全提示输入，不写入文件。空账号场景使用空字符串；空密码场景在密码提示时直接回车。

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
python run.py
```

正常登录不要使用 `--login` 预先登录选项，也不要注入历史登录态。存在人工验证码的脚本不能使用 `--headless`。
